# File ZIP: PRD dan Prompt Web FileFlow

Paket ini berisi:
- `PRD_FileFlow.md` — Product Requirements Document untuk aplikasi konversi file dan penghapus background.
- `PROMPT_WEB_FileFlow.md` — prompt lengkap untuk AI coding tool agar membangun aplikasi web.

## Catatan
Dukungan “format apa pun” harus diwujudkan sebagai arsitektur adapter yang dapat diperluas. Tidak semua format atau pasangan format dapat dikonversi secara valid. Paket ini menekankan agar UI hanya menawarkan konversi yang benar-benar didukung, dan tidak sekadar mengganti ekstensi file.

Lihat kedua file Markdown untuk spesifikasi lengkap.
